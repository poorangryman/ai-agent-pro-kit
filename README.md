## Зачем нужен этот репозиторий

При регулярной работе с AI-ассистентами (Cursor, Claude Code, Windsurf, Antigravity, ChatGPT) возникают две постоянные проблемы:

| Проблема без набора | Решение с AI Agent Pro Kit |
| :--- | :--- |
| **Амнезия ИИ**: в новом чате модель забывает стек, правила и прошлые договоренности, предлагая несовместимый код. | **`agent-memory`**: структурированное хранение контекста и архитектурных решений (ADR) по правилам канонического владения данными. |
| **Шаблонность и «слоп»**: однотипные неоновые градиенты, карточки с серыми тенями, рекламный пафос в текстах и очевидные комментарии к очевидному коду. | **`antislop`**: 38 правил качества, калибровка тональности и чек-лист Delivery Gate (проверка перед сдачей задачи). |

```

├── skills/                      # Библиотека агентских скиллов (Agent Skills Standard)

│   ├── antislop-copywriting/    # Текст без рекламных штампов
│   ├── antislop-human/          # Естественные формулировки и проверка доступности (a11y)
│   ├── antislop-layoutmobile/   # Адаптивная mobile-first верстка
│   └── antislop-ui/             # Функциональный интерфейс без шаблонных украшений
├── templates/
│   └── memory/                  # Готовая структура памяти для проекта
├── prompts/                     # Универсальные промпты для веб-чатов
├── .cursor/rules/               # Правила для Cursor IDE (.mdc)
├── rules/                       # Правила загрузки для Antigravity
├── .windsurfrules               # Правила для Windsurf Cascade
├── CLAUDE.md                    # Инструкции для Claude Code
├── install.ps1                  # Установка для Windows
├── install.sh                   # Установка для Linux и macOS
└── GUIDE.md                     # Руководство с примерами
```

## Каталог скиллов

В репозитории 7 скиллов, разделенных по назначению:

### 1. Долговременная память (Agent Memory)
| Скилл | Назначение | Когда используется |
| :--- | :--- | :--- |
| **`agent-memory`** | Управляет долгосрочным контекстом, проектами и правилами. Вводит типизацию записей (`[FACT]`, `[RULE]`, `[DECISION]`, `[UNKNOWN]`), политику актуальности и сохраняет архитектурные решения между сессиями. | При вопросах о стеке, архитектуре, истории проекта или фиксации новых решений. |

### 2. Фильтр качества (Anti-Slop Quality Gate)
| Скилл | Назначение | Когда используется |
| :--- | :--- | :--- |
| **`antislop`** | Базовое ядро правил качества. 38 правил (R-01–R-38), шкалы ритма/энергии и чек-лист Delivery Gate. | При генерации интерфейсов, верстки или текстов. |
| **`antislop-code`** | Убирает очевидные комментарии (`// увеличиваем счетчик`) и оставляет пояснения только к нетривиальной логике, краевым случаям и безопасности. | При написании, рефакторинге и ревью кода. |
| **`antislop-copywriting`** | Убирает штампы (*«в современном мире»*, *«раскройте потенциал»*, *«погрузимся»*). Делает текст прямым и информативным. | При написании статей, документации, заголовков и текстов кнопок. |
| **`antislop-ui`** | Защищает от шаблонного оформления: одинаковых градиентов, необоснованных карточек с тенями и бессмысленных иконок. | При создании страниц, стилей и компонентов. |
| **`antislop-layoutmobile`** | Контролирует мобильную верстку: зоны нажатия (tap targets >= 48px), вьюпорты, отсутствие горизонтального скролла и базовую эргономику. | При верстке адаптивных экранов и интерфейсов. |
| **`antislop-human`** | Убирает приторную вежливость в диалогах, проверяет контрастность текста и доступность интерфейса (a11y). | При генерации диалоговых сценариев и верстке. |

## Быстрый старт

### Windows (PowerShell)
```powershell
.\install.ps1
```

### macOS / Linux (Bash)
```bash
chmod +x install.sh && ./install.sh
```

### Для браузерных чатов (ChatGPT, Claude Web, Gemini Web)
Скопируйте текст из [`prompts/UNIVERSAL_AGENT_PROMPT_RU.md`](prompts/UNIVERSAL_AGENT_PROMPT_RU.md) в поле Custom Instructions или системный промпт проекта.

## Как устроена память проектов

В папке `templates/memory` подготовлена структура для фиксации контекста:
- `USER_CONTEXT.md`: ваши постоянные правила, стек и требования.
- `projects/<проект>/`: технический паспорт проекта, архитектура и история решений (`decisions/`).
- `channels/<канал>/`: редакционная политика и позиционирование для каналов и блогов.
- Принцип одного источника истины: модель читает только нужный контекст перед задачей и фиксирует новые решения при их утверждении.
