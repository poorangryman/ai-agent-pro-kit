# Master Knowledge Index

Registry of reusable domain knowledge, proven methodologies, and evergreen principles.

## Structure
- `knowledge/<domain>/00-INDEX.md` — Domain index
- `knowledge/<domain>/<topic>.md` — Topic knowledge file

## Domains
- **`architecture/`**: System design patterns, scalability principles, concurrency patterns.
- **`marketing/`**: Positioning methodologies, behavioral psychology, conversion models.
- **`engineering/`**: Idiomatic language patterns, clean testing setups, CI/CD blueprints.

## Contribution Rule
Only add durable knowledge that materially improves future agent generations. Do not copy-paste third-party manuals that are frequently updated online.
