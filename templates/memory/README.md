# Agent Memory Starter Template

This folder provides a plug-and-play directory structure for setting up long-term memory for your AI coding agents (Antigravity, Cursor, Windsurf, Claude Code, ChatGPT Projects).

## Quick Setup

1. Copy the contents of this folder into a dedicated memory folder (e.g., `~/.ai-memory` or a `memory/` directory in your workspace).
2. Rename `USER_CONTEXT.template.md` to `USER_CONTEXT.md` and fill in your profile, preferences, and guidelines.
3. For each active project, duplicate `projects/project-template` into `projects/<your-project-name>`.
4. Point your agent to this memory folder using the instructions in the main repository `GUIDE.md`.
